## 这个仓库是什么

一条已经跑通的链路：本机网页控制台（登录 / 看数据 / 预览 / 提交）＋ 协议库 ＋ 抓证工具。
在**你自己的电脑**上，用**你自己的账号 token**，复现一次真机打卡请求的形态。

**不包含**：任何预置证书或私钥、任何真实账号 / token / 学号 / 轨迹数据、任何代跑服务。

> 合规提示：把本仓库用于伪造体测成绩、代跑、刷学分，很可能违反你所在学校的规章和平台条款，
> 后果由使用者承担。仓库里的免责声明不是许可。

### 打开脚本后上不了网 / 小程序报「网络接口错误」？

按顺序做，第 1 步通常就够了：

| 顺序 | 做什么 | 说明 |
|---|---|---|
| 1 | 双击 `启动脚本/6-一键修复网络.bat` | 按备份还原你原来的代理 → 清残留 PAC → 重置 WinHTTP → 清 DNS |
| 2 | 双击 `启动脚本/0-首次使用-安装证书.bat`，弹窗点【是】 | 根证书不在「受信任的根证书颁发机构」时，所有 HTTPS 握手都失败，小程序固定报「网络接口错误」 |
| 3 | 双击 `启动脚本/5-环境自检.bat` | 看 `固定代理` / `PAC` / `根证书` 三行是否 OK |
| 4 | 关掉所有抓包黑窗口，再重开控制台 | 端口被旧进程占着时，新抓包起不来 |

旧版为什么会断网（现已修）：

- 抓包把**系统全局代理**指向 `127.0.0.1:8086`，MITM 一挂、代理还留着 → 整机所有网站都指向死端口；
- 启动脚本还会直接写 `ProxyEnable=0`，把用户自己的 Clash / 公司代理**一并关掉**；
- 现在默认走 **PAC 模式**：只有 `*.lptiyu.com` 等乐跑域名进抓包端口，其他网页完全直连；
- 另加**看门狗**：MITM 进程 3 秒不在了，自动还原代理并提示。

详细排障： [`文档/网络故障排查.md`](文档/网络故障排查.md)。

### 提交一直卡在「提交中…」

v2.4 起网页上多了 **「网络自检」** 按钮，提交前先点它：

| 自检结果 | 含义 | 怎么办 |
|---|---|---|
| 三项全「通」 | 网络侧没问题 | 查 token 是否被顶号（小程序重登过）、系统时间是否准确 |
| 只有 `OSS 轨迹上传` 不通 | 轨迹文件传不上去，提交必卡 | 换手机热点，或避开 20:00–23:00 |
| 外网基线也不通 | 校园网没认证 / Portal 掉线 | 浏览器开任意网站，看是否跳认证页 |

失败时会直接告诉你**卡在哪一步**（`upload` / `stop` / `review`）和已耗时，不会再无声卡死。
卡在 `stop` / `review` 时，先去「本学期记录」看有没有新记录，再决定是否重试——接口没有幂等键。

## 轨迹逼真化参数（对照 LePaoRunner）

轨迹不是"画个圈标个距离"，而是按**真人行为模型**生成的。参数体系对齐
[LePaoRunner](https://github.com/zgbjhk/LePaoRunner) 的 `run` 配置组——它走模拟器 GPS 注入，
本仓库走协议直连，但**要骗过的是同一套行为判定**。

### 核心：按时间采样，不是按距离采样

| | 朴素实现 | 本实现 |
|---|---|---|
| 采样依据 | 固定距离取点（如每 6.4 m） | **每 1 秒取一个点** |
| 点间距 | 恒定 | 随速度在 1.5~3.4 m 间浮动 |
| 时间轴 | 距离 ÷ 配速，完美线性 | 由速度曲线积分 |
| 速度标准差 | **0**（一眼假） | 0.24~0.34 |

### 参数对照表

| 参数 | 本实现 | LePaoRunner | 说明 |
|---|---|---|---|
| `sample_hz` | **1.0** | `update_hz: 1.0` | 每秒一个轨迹点 |
| `speed_jitter_pct` | **6.0** | `speed_jitter_pct: 6.0` | 配速波动 ±6%，过一阶低通（0.6/0.4）模拟加减速惯性 |
| `gps_noise_m` | **1.2** | `gps_noise_m: 1.8` | 定位漂移；**必须远小于点间距**，否则轨迹画成锯齿 |
| `warmup_s` | **45** | `warmup_s: 45.0` | 起步 55%→100% 线性爬升 |
| `cooldown_s` | **20** | `cooldown_s: 20.0` | 收尾 100%→45% 线性回落 |
| `pause_probability` | **0.65** | `traffic_events: true` | 65% 概率插入 1~2 次停顿 |
| `pause_seconds` | **2~7** | — | 单次停顿时长，速度归零 |
| `lap_drift_m` | **1.6** | `lap_line_drift_m: 1.6` | 每圈起跑线横向漂移，三圈一循环，轨迹不再完全重合 |
| `stride_m` | **1.15** | `cadence: 0`（自动） | 步幅，用于把速度换算成步频 |
| `cadence` | **150~190** | — | `step_info` 由逐秒速度反推，与距离/配速自洽 |
| `corner_radius_m` | **40.82**（田径场弯道） | `corner_radius_m: 6.0` | 弯道几何；本实现直接采用标准田径场模型（移植自 run.bupt.app 的 `Qt()`） |

### 逼真化前后对比

| 检测点 | 逼真化前 | 逼真化后 |
|---|---|---|
| 速度标准差 | 0（恒速） | 0.24~0.34 |
| 首末速度渐变 | 无 | 45 s 爬升 / 20 s 回落 |
| 中途停顿 | 无 | 0~2 次，每次 2~7 s |
| 点间距 | 恒定 6.4 m | 1.5~3.4 m 浮动 |
| 每圈重合度 | 完全重合 | 横向漂移 ±1.6 m |
| 步频与速度 | 无关（纯随机） | `v×60/stride`，自洽 |
| 步幅 | 波动大 | 稳定 1.15~1.2 m |

代码位置：`程序/lepao/realism.py`（行为模型）＋ `程序/webapp/server.py: build_run()`（几何 × 速度曲线）。

## 抓包证书：本机生成，不入库

`启动脚本/0-首次使用-安装证书.bat` 调用 `程序/工具/mitm_debug_proxy.py --init`，
用本机 `openssl` **现场生成**一把只属于这台电脑的根 CA，装进「当前用户 → 受信任的根证书颁发机构」，
再按访问到的域名现签叶证书。

- 私钥写在 `程序/_private/mitm_ca/`，已列入 `.gitignore`，**永远不要提交、不要发给别人**；
- 换电脑要重新生成一次（证书按用户安装，不随文件夹走）；
- 想卸载：`Win+R` → `certmgr.msc` → 受信任的根证书颁发机构 → 找到 `lepao-debug-ca` → 删除。

> 为什么不再预置证书：共用同一把根 CA 私钥会让所有下载者互相能中间人。
> 这个包旧版本曾随包带 45 个私钥，公开前已全部移除（见 `MODIFICATIONS.md`）。

## 抓包不再拖垮网络（v2.3）

老版本最让人崩溃的地方：点「一键获取凭证」之后，浏览器打不开网页、微信小程序报
「网络接口错误」，得关掉一切、手动去 `inetcpl.cpl` 里把代理关掉才能恢复。

现在的做法：

| 环节 | 老版本 | 现在 |
|---|---|---|
| 代理范围 | 系统全局 `127.0.0.1:8086` | **PAC**：只有 `*.lptiyu.com` 等乐跑域名进代理，其余 `DIRECT` |
| MITM 挂掉 | 代理留着 → 整机断网 | 看门狗 1.2 s 轮询，进程没了 3 s 内还原代理 |
| 启动清理 | 直接 `ProxyEnable=0`，连 Clash 一起关 | 只清「指向本机 8081/8086/8090」的残留，自己的代理不动 |
| 退出还原 | 只还原 `ProxyEnable/ProxyServer` | 四项全还原：`ProxyEnable / ProxyServer / ProxyOverride / AutoConfigURL` |
| 控制台自身 | `127.0.0.1:8780` 也被代理，MITM 卡住时页面全白 | PAC 里 `DIRECT`，且全局模式写 `ProxyOverride` 排除本机 |

兼容性：少数客户端不读 PAC（尤其某些定制微信 / 老版本），这时点网页上的
**「兼容模式（全局代理）」**，或命令行 `python 工具\capture_launcher.py --global`。

证书仍是硬前提：**根证书没装进受信任根，PAC 配得再对也抓不到 HTTPS，小程序会一直报
「网络接口错误」**——先跑 `0-首次使用-安装证书.bat`，弹窗点【是】。

## 运行环境

- Windows 10 / 11（x64）
- **Python 3.8+**，安装时勾选 `Add python.exe to PATH`
- **openssl**（步骤 0 生成证书用；装 Git for Windows 就自带，脚本会自动去找）
- 电脑版微信（登录自己的号，能打开对应小程序）

不需要：mitmproxy、pycryptodome、Android root、FakeLocation、爱思助手。

这两个文件含**真实 token**，已列入 `.gitignore`，不要外发、不要提交。
