# 研究记录（协议字段语义与实证结论）

> 本文件是协议层研究笔记，记录"为什么这样实现"。所有结论均来自真机抓包 + 逐字段对照验证。
> 结论标注了证据代号（R3/R4/R5/P11/P15/P17/R_OK_REF/R_GOLD_REF 等），代原始抓包样本序号。

## 1. 请求形态

```
POST /v3/api.php/{Module}/{method}
body = ostype=5&data=<AES(json(公共参数 + 业务参数 + sign))>
```

公共参数：`uid, token, school_id, term_id, course_id, class_id, student_num, card_id,
timestamp, version, nonce, ostype`；`sign` 为按键升序 `k+v` 拼接后再拼 secret 的 MD5。

- 响应同构：`data` 字段为密文时先解密再解析；`status=101` 恒表示 token 失效。
- 门后业务层信任 `uid` 参数（读面 IDOR 已实证）——**本实现的纪律是只写本人 uid**。

## 2. 真机指纹头组（transport）

- 头名**全小写**、顺序锁定：`content-length, content-type, [flag], charset, referer,
  user-agent, accept-encoding`。
- `loginByCode` / `stopRunV278` 额外携带 `flag: [object Boolean]`——这是小程序侧
  `String(Boolean)` 的缺陷产物，服务端并不校验语义，但缺头会与真机形态不一致。
- `accept-encoding` 随 brotli 可用性切换（`gzip, deflate, br` / `gzip, deflate`），
  响应按 `Content-Encoding` 解码。

## 3. 出口绑定（R3 修正）

早期结论"WAF 拒绝代理 → 必须直连（405）"是**误诊**：当时 token 恰好已死（死亡形态恒 101）。
实测：业务会话与**登录时的出口路径同态**——真机走 `系统代理 → mitm(8081) → Clash(7897)`，
同 token 直连或纯 Clash 一律 101，走同一条 mitm 链则 200（节点局部会话）。

⇒ `proxy` 不是例外开关而是**常态**：`config.environment.api_proxy=127.0.0.1:8081`，
由 `capture`/`run` 自动保证链在位。

## 4. token 生命周期（2.1.0 定版）

- 单活动会话消耗品：每次 `loginByCode` 轮换旧号；无统一 TTL；死亡恒 101。
- 提交完成即 `mark_consumed`，该成员下次打卡前必须重新 capture。
- **真门 = `getTermList`（WpRun）**；`getSchoolInfo` 是免 token 公开口，用它做存活判断会假阳性（已弃用）。
- 顶号看门狗：检测到新登录即中止当前任务，避免用旧 token 提交。

## 5. 打卡闭环时序（pipeline）

```
0 getTermList(真门) → getSchoolInfo
1 beforeRunV260           跑区/打卡点/时间规则（min_distance/max_distance 窗口）
  [可选] setRunZone
2 getTermList + getTermRunRecord  当日额度预检
3 getTimestampV278        服务器时间（所有时间戳以它为准）
4 轨迹生成                 template/math, 重试直到覆盖所有打卡点且在距离窗口内
5 时间轴 + log_data + step_info
6 record_file 命名 + 组装 stopRun 业务参数
  [dry-run 到此为止：零写入]
7 getOssSts → OSS multipart 上传轨迹 txt
8 stopRunV278(flag)       提交
9 recordDetailV270        复核（权威 status）
```

## 6. 轨迹文件与 OSS 上传（record，逐字节复刻）

- `record_file` = `run_record/{date}/{dir3}/{ms}-{n}.txt`（无 `Public/Upload/file/` 前缀）。
- OSS 表单 key = `Public/Upload/file/` + `record_file`。
- `dir3` = 构造 key 时刻 `ms % 1000`；文件名 ms **晚于** dir 时刻几~几十 ms（真机两次 `Date.now()`）。
- 表单字段顺序：`OSSAccessKeyId, key, policy, signature, x-oss-security-token, file`（无 callback）。
- boundary = `----MultipartBoundary--` + 27 位随机字符；policy 含 `content-length-range 0~1GB`。
- `file` 部分 filename 用本地落盘的纯毫秒名（比 key 文件名早几十 ms）。

## 7. 轨迹引擎（track）

### 7.1 template（P11 主力，反指纹）

- 真人模板 226 点，服务端判 `record_status=1`；保留真实 `s`（速度，含停走段）/`b`/`c` 字段序列。
- ENU 相似变换：相位对齐（环上最小代价旋转）+ 尺度 + 旋转 → 目标距离缩放 → 平滑 GPS 噪声
  （一阶自回归，偶发跳变）。
- 速度字段按 `pace_factor` 缩放并叠加高斯扰动，首点去掉 `s`（真机首点无速度）。

### 7.2 math（备用）

多圈锚点环 + 速度模型（基础速度 + 周期正弦 + 打卡点减速扫描）+ 末段两步收尾。
**注意**：数学圆形态曾被服务端异步作废（`status=5`），先例在前——默认不用。

### 7.3 log_data 首通过语义（2026-09-08 修正）

真人语义（035 明文，`status=1` 有效）：

- `coordinates` = **通过时刻**的 GPS（轨迹点原值，部分点与轨迹 0.0m 重合，个别点 13m 偏差也被接受）。
- `time` = 首通过墙钟偏移（s 积分时间映射，起点近的点前载到 +4s/+9s）。
- `distance` = **首通过时累计公里**（`0.156→0.16`、`0.223→0.22`、`0.000→"0.0"` 精确吻合）。
- `order` = 配置点序，**不按时间排序**（真人记录里 155s 的点排在 4s 的点之前）。
- 修正前的 bug：`distance` 误用 haversine 米值（4.59 > 全程 2.31km）→ 同步"打点异常"。

### 7.4 step_info

桶数 = `used_time // 60 + 1`，每桶稀疏不规则值（含 0~6 与 70~92 两档特例），总和落在 180~360 区间。

## 8. 提交与判定

- `record_failed_reason` **字段名是坑**：服务端也用它装**肯定**判定文本
  （`"自动确认有效"` = 过审；否定例：`"打卡点异常"`）。
- positive 判定：`reason` 为空，或含"有效"且不含"无效/不/异常"。
- `record_status ∈ {0,1}` 且 positive → 过审（exit 0）；已建记录但 not positive → exit 5。

## 9. H5 面（h5api，与 v3 主 API 的差异）

ThinkPHP 5.0.14 独立应用，双鉴权通道：

- **token 通道**：`access_token + uid`（uid 与 token 绑定，无 IDOR）；`sign` 可为空（空不校验）；
  **无时间戳新鲜度校验**（老报文可重放）。
- **session 通道**：`PHPSESSID`（学号+密码+验证码登录后，响应无 token 字段）。
- 登录链（P15）：`Login/getToken` → `Login/verify?token=..&random=..`（PNG 验证码 + Set-Cookie，
  PHPSESSID 每请求轮换，必须跟最新值）→ `Login/login`。
- 校验顺序：验证码 → 学号/密码；实测 5 连错不锁。

## 10. 已知坑与先例

| 现象 | 根因 | 处置 |
|---|---|---|
| 一直"等待登录流量" | mitm 根证书未受信，TLS 握手被拒 | `cli.py cert --install` |
| 直连必 101 | 出口绑定：业务与登录出口须同态 | 走 mitm 链，不旁路 |
| 提交成功但小程序无记录 | windowed 模式下日志进黑洞 + 模板路径套娃 | 传 `log_fn`；`_find_template` 兼容套娃包 |
| 打点异常 | `log_data.distance` 用错单位 | 用首通过累计公里 |
| 记录 status=5 | 数学环形态被异步作废 | 用 template 引擎 |
| 抓号后立刻失效 | 小程序被再次打开顶号 | 抓完立刻提交；开看门狗 |
