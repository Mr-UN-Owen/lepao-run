## 一、这个包是干什么的

一句话：不碰手机定位、不给微信装任何模块，直接在电脑上生成一条「真人形态」的跑步轨迹，通过平台自己的接口提交上去，成绩落在你的账号里。

为什么叫「虚拟定位」：位置数据确实是被「造」出来的，但造它的地方不是手机 GPS，而是电脑上的协议实现。小程序读定位走的是微信自己的定位通道，安卓上挂「模拟位置」应用基本无效，而 iOS 上改坐标又会因为缺少步频/速度曲线被判无效。本包绕开这一层，直接让服务端收到一条配速、步频、打卡点首通过都自洽的轨迹。

## 三、首次使用：按顺序做 6 步

下面每一步都写清了「双击哪个文件、点哪个按钮、按哪个键」。全部做完大约 5 分钟。


### 第 1 步：解压（不要只解一半）

1. 按 Win+E 打开「文件资源管理器」，找到收到的压缩包。
1. 在压缩包上点鼠标右键 → 选「全部解压缩…」→ 点「提取」。
1. 进入解压出来的文件夹，应当能看到 程序 / 启动脚本 / 文档 / 示例配置 这四个文件夹和 README.md。
> **提示**：不要放在 OneDrive、坚果云等同步目录里；也不要只把文件夹拖出来用（会丢 _private 里的会话记录）。


### 第 2 步：生成并安装本机抓包证书（只需一次）

1. 进入「启动脚本」文件夹，双击 0-首次使用-安装证书.bat。
1. 脚本用本机 openssl 现场生成一把只属于这台电脑的根证书；弹出「安全警告」时点【是】（装到当前用户，不需要管理员）。
1. 黑窗口最后一行出现 [OK] 安装完成，即成功；按任意键关闭窗口。
> **提示**：证书和私钥只生成在本机 程序\_private\mitm_ca\，不会上传；这个目录不要发给别人，也已在 .gitignore 里。

> **提示**：为什么必须装：不装的话小程序不会把 HTTPS 交给本机代理解密，抓证会一直等到超时。装的是本机生成的 lepao-debug-ca，卸载方式见第六章最后一行。


### 第 3 步：环境自检（确认这台电脑能跑）

1. 双击 5-环境自检.bat。
1. 看输出：每一行都应以 [OK] 开头；最后一行应是「结论：环境可用」。
1. 如果有 [X] 行，按提示处理（最常见是没装 Python 或端口被占用），然后重新双击本文件。
> **提示**：自检会检查：Python 版本、核心库导入、加密后端、证书文件、证书是否已信任、openssl、8780 与 8086 端口、当前系统代理。


### 第 4 步：启动网页控制台

1. 双击 1-启动网页控制台.bat。
1. 等 1~2 秒，默认浏览器会自动打开 http://127.0.0.1:8780，页面上是「乐跑控制台」登录框。
1. 这个黑窗口就是服务本体：使用期间不要关；关掉它等于停止服务。
> **提示**：浏览器没自动打开：手动打开浏览器，在地址栏输入 127.0.0.1:8780 后按回车。


### 第 5 步：一键抓凭证并登录（每天都要做）

1. 在登录页点按钮「一键获取凭证（自动抓包）」。页面出现「抓包已就绪」字样。
1. 按 Win+D 回到桌面，找到微信图标双击打开；如果微信已经开着，先在任务栏微信图标上点右键 → 选「退出」，再重新打开。
1. 在微信左侧点小程序面板 → 打开「公大跑者」→ 进入跑步首页（能看到开始跑步/跑区那个页面）。
1. 按 Alt+Tab 切回浏览器，等 3~15 秒：host / school_id / uid / token 四个框会自动填好，提示「凭证已填入上面的框」。
1. 点按钮「登录」。页面切换到控制台，能看到学校、学期、本学期里程、跑区、打卡点坐标。
> **提示**：抓包期间不要在小程序里反复退出登录/重新进入，会把刚抓到的 token 顶掉。

> **提示**：页面 240 秒抓不到会自己停下并提示，此时系统代理已被自动还原，网络不会受影响。


### 第 6 步：生成轨迹并提交

1. 看右栏「生成与提交」：目标距离（公里）填 3.05 ；配速（秒/公里）填 310（= 5 分 10 秒/公里）。
1. 点按钮「生成轨迹预览」。左侧地图出现蓝色轨迹线，地图上被经过的打卡点变绿并标出名字。
1. 看按钮上方那行字，必须是「✓ 全部覆盖」。若是「✗ 有遗漏」，把距离改成 3.2 或把配速改成 300 再点一次「生成轨迹预览」。
1. 点按钮「提交（实验性）」。弹出确认框，核对距离/用时/打卡点后点【确定】。
1. 等右下角出现成功提示，下拉「跑步记录」面板，最新一条记录出现在列表里即完成。
> **提示**：提交前若页面提示「今天已经有 N 条【有效】记录」，说明今天已经打过卡，【提交】按钮会变灰——这是保护，不要去绕。


## 四、每天重复使用的流程

首次装好之后，以后每天只有 3 步：

1. 双击 启动脚本\1-启动网页控制台.bat（黑窗口别关）。
1. 网页上点「一键获取凭证（自动抓包）」→ 打开微信「公大跑者」进跑步页 → 等自动填好 → 点「登录」。
1. 点「生成轨迹预览」→ 确认「✓ 全部覆盖」→ 点「提交（实验性）」→ 弹窗点【确定】。
> **要点**：为什么每天都要重新抓：token 是「单会话消耗品」，提交完成即失效；小程序重新登录也会顶掉旧的。所以不要指望登录一次用一周。

> **要点**：每天只记 1 次有效成绩（服务端规则）：同一天重复提交不会多算，只多一条无效记录。


## 五、参数怎么填（附服务端规则表）

| 参数 | 推荐值 | 规则范围（服务端下发） | 说明 |
|---|---|---|---|
| 目标距离 | 3.05 km | 3.00 ~ 20.00 km | 低于 3.00 直接判无效；取 3.0~3.2 最稳 |
| 配速 | 310 秒/公里 | 3'00" ~ 5'30"（即 180~330 秒/公里） | 数字越小越快；310 属于中等偏慢，通过率高 |
| 用时 | 自动计算 | —— | = 距离 × 配速，页面预览里会显示 |
| 打卡点 | 自动选 2 个并覆盖 | 每次随机 2 个，必须途经 | 页面会标出「覆盖打卡点 12,18」这类编号 |
| 时间窗 | 自动 | 06:00 ~ 22:00 | 服务器按提交时刻判，夜里不要提交 |
| 每日次数 | 1 次 | min_num = 1 | 提交成功即当日完成 |

> **提示**：距离/配速都在页面上改：点输入框 → 按 Ctrl+A 全选 → 输入新数字 → 点「生成轨迹预览」重新生成即可。


## 六、出错怎么办（照着查）

| 现象 | 原因 | 按这个做 |
|---|---|---|
| 一直显示「抓取中」，240 秒后超时 | 证书没生成 / 装了但微信没重启 | 双击 0-首次使用-安装证书.bat 生成并安装；微信任务栏右键「退出」后重开；再点一键获取 |
| 提示「MITM 没起来，代理设置一个字都没动」 | 8086 端口被占（上一个抓包窗口没关） | 关掉所有黑窗口；仍不行就重启电脑再试 |
| 提示「自动改系统代理失败」 | 权限不足或安全软件拦截注册表写入 | 页面会给出「我已设好代理，开始抓包」按钮：先手动把 设置→网络和 Internet→代理 设为 127.0.0.1:8086，再点它 |
| 登录报 [101] | token 失效，或抓包时的出口与提交时不一致 | 重新抓一次；抓包和提交期间不要开/关 VPN、Clash |
| 提交按钮是灰的、点不动 | 轨迹没覆盖全部打卡点 | 把距离改 3.2、配速改 300，重新点「生成轨迹预览」 |
| 服务端判「速度过慢 / 跑步时间异常」 | 配速或时间轴不在规则内 | 配速填 300~320；距离 3.0~3.2；不要用 6 分以上的配速 |
| 提交成功但记录里看不到 / 显示无效 | 服务端异步复核 | 等 5~10 分钟，按 F5 刷新记录列表再看 |
| 浏览器、微信突然上不了网 | 抓包窗口被强关，系统代理没还原 | 双击 4-关闭系统代理-救急.bat |
| 网页打不开 / 一直转圈 | 控制台黑窗口被关了 | 重新双击 1-启动网页控制台.bat，再刷新页面（F5） |
| 双击 bat 黑窗口一闪就没了 | 没装 Python，或装的时候没勾 Add to PATH | 装 Python 3.8+（勾选 Add python.exe to PATH），重开窗口，先跑 5-环境自检.bat |
| 想卸载证书 | —— | Win+R → 输入 certmgr.msc → 回车 → 受信任的根证书颁发机构 → 证书 → 找到 lepao-debug-ca → 右键删除 |


## 七、导入到其他电脑，功能还能生效吗

结论：能生效，但有 3 件事必须在新电脑上重做一次。代码与参数都不含这台电脑的私有路径，换机器不用改任何文件。

| 能力 | 换电脑后 | 为什么 |
|---|---|---|
| 网页控制台、轨迹生成、提交逻辑 | 直接生效 | 纯 Python 标准库实现，路径全相对，无盘符硬编码 |
| 加密算法（AES-128-CBC / SignMD5） | 直接生效 | 包内自带纯 Python AES，缺 pycryptodome 会自动回退 |
| 抓证书（MITM 解密小程序 HTTPS） | 要重装一次证书 | 证书按「当前用户」安装，存放在注册表/用户证书库，不随文件夹走 |
| 抓 token | 要重新抓 | token 是与会话、出口绑定的消耗品，不能拷来用 |
| 抓包根证书（lepao-debug-ca） | 要重新生成一次 | 私钥不随包分发；新电脑装好 openssl 后双击 0 脚本现场生成 |
| config.json / 会话缓存 | 不会带过去（也不该带） | 含真实 token，已列入 .gitignore |
| bat 启动脚本 | 直接生效 | 已改为自动探测 py / python / python3，不再写死解释器路径 |
| 手机端虚拟定位（安卓 Hook 等） | 不在本包内 | 本包走协议路线，不依赖手机改定位 |


### 新电脑上的操作顺序（4 步）

1. 装 Python 3.8+，安装界面勾选 Add python.exe to PATH。
1. 把整个文件夹拷过去（U 盘 / 网盘都行），路径别太深、别含特殊符号。
1. 双击 启动脚本\5-环境自检.bat，确认全绿。
1. 双击 0-首次使用-安装证书.bat 生成并安装证书 → 双击 1-启动网页控制台.bat → 重新抓一次凭证登录。

### 什么情况下会失效

- 平台改了接口或换了域名：需要在 程序\webapp\lplib.py 里改 host/签名逻辑（一般用户不用管，先跑自检看域名是否还通）。
- 学校换了打卡规则（比如要求 3.5km 或加人脸）：页面参数跟着服务端下发变，按第五章的表调整即可。
- 电脑上没有 Python，或装的是 Microsoft Store 版 Python（会出现假 python.exe 别名）：改用官网安装包。
- 公司/学校网络强制走代理或做了 TLS 拦截：抓证会失败，换手机热点再试。

## 九、进阶用法（可选，新手跳过）

命令行流水线（需要先复制配置）：把 示例配置\config-案例816.json 复制到 程序\config.json，然后：

```bat
cd /d 程序
python cli.py account add 张三 2023xxxxxx --alias 张三    注册成员（= 抓证白名单）
python cli.py capture --member 张三                        抓 token
python cli.py build  --member 张三                         干跑（零写入）
python cli.py submit --member 张三                         真提交
python cli.py watch  <record_id> --member 张三             复核
```

旧版控制台：双击 启动脚本\9-进阶-启动旧控制台8770.bat，服务起来后浏览器打开 127.0.0.1:8770。

局域网模式：双击 启动脚本\2-启动网页-局域网模式.bat，手机在同一 WiFi 下可用局域网地址打开（无密码，仅限自家网络）。

## 附：一次提交在后台发生了什么（技术向）

1) beforeRunV260：拿学期、跑区、打卡点坐标、当日额度、参数规则表（时间窗/里程/配速/打卡点数）。

2) 本机生成轨迹：按跑区几何 + 随机 2 个打卡点合成环线，配速恒定，步频分桶，首点/末点时间轴包住起止时刻。

3) 上传轨迹文件到 OSS（STS 临时凭证），拿到文件地址。

4) Run/stopRunV278：提交跑区模式的记录（必须用跑区接口，自由跑接口不计成绩）。

5) 服务端复核：校验 里程 → 配速 → 时间轴 → 打卡点首通过 → 每日唯一；通过后记录 status = 有效。

> **提示**：校验顺序决定了报错顺序：配速不合格时只会报「速度过慢」，只有配速过了才会暴露时间轴问题。所以先修配速，再看时间。
