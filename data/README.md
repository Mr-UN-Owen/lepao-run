# data/ —— 轨迹模板目录

本目录存放**轨迹模板**（`track.py` 的 template 引擎读取）。

## 规矩

1. **真实个人轨迹不入库**：含真实身份/位置的数据一律不放进本目录，`.gitignore` 已排除
   `data/*`（仅放行本 README 与净化模板）。
2. **净化模板**：`data/真实轨迹_035明文.json` 形态为 226 点，字段
   `{"a": 纬度, "o": 经度, "s": 速度, "b": ?, "c": ?}`，**无任何身份字段**。
   上游仓库以"净化模板"形式分发；本仓库不随附该文件，请自行准备等价模板。
3. **自备模板**：可从自己的有效记录里提取坐标/速度序列后清洗掉身份字段，
   或用 `track.math_track()` 生成合成轨迹先行调试（注意：数学环形态曾被服务端异步作废）。
4. **校验**：模板点必须能与 `beforeRun` 返回的打卡点做相似变换（相位/尺度/旋转），
   且生成轨迹要覆盖所有打卡点（`anchor_cover ≤ 40m`）。

## 字段速查

| 字段 | 含义 | 备注 |
|---|---|---|
| `a` | 纬度 | float64；math 引擎会做 1/3600000° 量化 |
| `o` | 经度 | 同上 |
| `s` | 速度（m/s） | 含停走段；首点通常无 `s` |
| `b` | 状态位 | 打卡点附近出现 1/2 |
| `c` | 精度/置信相关 | 字符串形式的两位小数 |

## 缺失时的表现

`track._find_template()` 找不到模板文件时，`build`/`submit` 会在第 [4] 步失败并提示路径。
把模板放到 `data/真实轨迹_035明文.json` 即可（打包形态与源码形态都做了兼容探测）。
